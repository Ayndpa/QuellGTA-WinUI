The Angela Shortcut Engine Gen 3 supports three operating modes:
2. Polling Mode (Power Saving): Active detection, querying the keyboard every 40ms to check whether the set hotkey is being pressed (25 ticks/s). Since it can only query keyboard information, mouse side buttons cannot be used as hotkeys. Additionally, if a key is pressed between two ticks, the hotkey will only be triggered in the next tick, causing a slight delay; if the key is pressed for too short a time, it may be missed. However, polling mode does not interfere with the keyboard message path, and the fixed cycle will not increase load due to high keyboard reporting rates, potentially improving battery life on laptops.
3. Proxy Mode (Compatibility): Passive triggering, by intercepting keyboard and mouse messages and checking key events one by one to determine if a hotkey has been activated. With multiple safeguards such as hotkey self-detection and automatic engine restart when a key fails, hotkeys are guaranteed to be immediately recognized, and mouse button information can also be used as hotkeys. However, proxy mode participates in the keyboard message transmission (like adding a checkpoint in the keyboard message path), which can increase keyboard delay in games on lower-performance computers and affect gameplay feel.
Recommendation: Prefer using Raw Mode and Polling Mode. If you need to use mouse side buttons as hotkeys, or if Raw Mode sometimes doesn  t work properly, you can enable Proxy Mode as well. All three modes can work simultaneously as backups for each other. If none of the three modes are enabled, hotkeys will not work.
