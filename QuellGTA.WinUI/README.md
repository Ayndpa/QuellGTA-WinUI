# QuellGTA · WinUI 3 移植版

把原版 QuellGTA（易语言，`工程文件/QuellGTA216.e`，build 0216 / V4.22.216）移植到 C# + WinUI 3。
沿用原项目的 GPL-3.0 协议。

功能逻辑对照原版代码移植；界面没有照搬原版（480×640 的选择夹 + 600 多项菜单），而是按「要做什么」重新分了页。

## 构建与运行

需要 .NET 8 SDK（Windows 10 1809 及以上，x64）。

```
dotnet build -c Release
bin\x64\Release\net8.0-windows10.0.19041.0\win-x64\QuellGTA.exe
```

- 非打包（unpackaged）程序，自带 Windows App SDK 运行时，不需要另外安装运行库。
- 清单要求管理员权限：防火墙规则、禁用网卡、暂停进程、热键穿透都需要（与原版一致）。
- 数据目录：`%AppData%\MageAngela\QuellGTA\`。配置文件是 `QuellGTA.WinUI.ini`，与原版的 `QuellGTA.ini` 分开，互不影响。

## 与原版的差异

- **删除一律进回收站**：原版删除 settings.xml、着色器缓存、args.txt 是直接删，这里都改成移到回收站。BattlEye 的公共文件例外（会被重新安装），仍是直接删除。
- **自编宏合并成一个宏库**：原版分「自编宏甲 / 乙」和「多槽位自编宏」两套，这里是一个不限数量的列表，每个宏有自己的热键和执行次数。脚本格式（`# QuellGTA-Mscript`）与原版互相兼容，可以用剪贴板导入导出。
- **宏停止时会松开按键**：原版强制停止宏时，已经按下的键不会松开；这里中止或结束时会把还按着的键和鼠标按钮松开。原版的 `MbUp` 实际执行的也是「按下」，这里按字面意思改成了松开。
- **电子令牌的存储**：原版用自设密码加密令牌；这里用 Windows 数据保护（DPAPI）加密，只有当前 Windows 用户能解开，不用另设密码，但文件拷到别的电脑上无法使用。原版的令牌代码导入导出、网络时间校准没有移植。
- **准星和计时**：原版是两个易语言窗口，这里是两个鼠标穿透的分层窗口，用 GDI+ 绘制。准星形状改为十字 / 圆点 / 圆环 / 十字加点 / 空心十字，不再支持用字符当准星和 RTSS 显示。
- **开机自启的任务名**是 `QuellGTAWinUIStartUp`，不会覆盖原版的 `QuellGTAStartUp`。
- **wmic 兜底改为 CIM**：新版 Windows 已移除 wmic，第三级强杀改用 `Get-CimInstance | Invoke-CimMethod Terminate`。
- **瞬间悬停里的那个按键是 Esc**：原版用支持库常量 `#_Lib0Const178`，反编译结果里看不到它的名字。从同一组常量的其他用法反推：173 在原版注释里写明是 Alt，179 被用作空格，170 和 178 在英语锁定里一起表示「回车或 Esc」，按键码从小到大排下来 178 是 Esc。含义是「取消退出提示」，游戏不会真的退出。移植版最初的两个版本把它当成了回车，已改正。未在真实游戏里验证。
- **UDP 指令只监听本机**：原版监听所有网卡，局域网里任何设备都能发指令；这里只接受 127.0.0.1 发来的。
- **语言切换只影响取自原版语言表的文字**（日志和大部分提示框）；移植版新写的界面文字只有简体中文。繁体由简体表按系统的简繁字形映射逐字转换。
- **检查更新查的是原版**：移植版没有自己的发布渠道，不会像原版那样自动下载并替换程序；只告诉你原版有没有比 Build 0216 更新的版本。
- **换机代码的压缩格式未验证互通**：标签沿用原版（`qtaPcs` / `qtaCtrl` / `qtaGfx` / `qtaIni`），里面是标准 ZIP；原版用易语言的压缩支持库，两边生成的代码能否互相识别没有测过。`qtaIni` 一定不互通，因为两边的配置项不同。
- **自动指纹改为内置**：原版把仓库里的 GTAFingerprinterCore 编译成单独的程序随游戏启停，这里把它的识别逻辑直接并进主程序，用热键触发。
- **自动挂机、粘贴等的按键**一律带扫描码发送。
- **原版的外置组件改成了内置实现**。原版把几个小程序（多数用 C / C++ 写）内嵌在主程序里，用的时候释放出来运行；移植版对照它们的源码用 C# 重写，不再释放和运行任何外部程序：
  - **WFP 断网**（WFPcon）：通过 P/Invoke 直接调用 `fwpuclnt.dll`，在自己的提供者和子层下添加出站阻止过滤器，各种范围对应的条件与原版调用 WFPcon 的参数一致。和原版不同的地方：IPv6 出站层也加了同样的过滤器；瞬间悬停用的是动态会话，程序一退出规则就自动消失。
  - **Dev 硬件断网**（devcon）：通过 SetupAPI 给网卡设备发「属性变更」请求来禁用 / 启用，和 devcon 内部的做法相同。网卡的设备实例路径从注册表按连接名查出。
  - **RTSS 锁帧**（RTSScon，原版注明基于 xanderfrangos/rtss-cli）：加载 RTSS 安装目录里的 `RTSSHooks64.dll`，调用它导出的配置文件函数来改帧数上限和锁帧开关。
  - **RTSS OSD**（RTSSosd，即 Erruar/RTSS-CLI）：直接往 RTSS 的共享内存 `RTSSSharedMemoryV2` 里写文字。和原版不同的地方：OSD 的排版是移植版自己定的（状态行用英文缩写 BLOCK / NIC / SOLO），计时的位置单独设置；签名里的中文不显示（原版是转成拼音）；「用 RTSS 显示」默认关闭（原版检测到 RTSS 就默认开）；只在游戏运行时显示。
  - **自动骇入**（AutoHack）：识别代码照原文逐句翻成 C#，截图和按键也在进程内完成。目前移植了「找数字」和「连线配对」两种；原版在画面上叠加显示识别过程的那层没有做，「连线配对」算出的算式改为写进日志。和原版不同的地方：等待骇入画面最多 60 秒（原版一直等到再按一次热键）。
  - **进程守护**（UEPcon）：本程序带 `guard <进程号>` 参数再启动一份当守护进程，逻辑照原版（每秒检查、12 秒心跳超时）。和原版不同的地方：默认关闭；管道名是 `QuellGTA_WinUI_UEP`；电脑睡眠醒来不会被误判成卡死；重启后的程序连续三次在 5 秒内退出就放弃；调试器附加时不启动。
  - **虚拟手柄**（JoystickSim）：在进程内用 `Nefarius.ViGEm.Client` 创建虚拟手柄，摇杆坐标的换算照原插件。同样需要另外安装 ViGEmBus 驱动。原版的「兼容模式」（改用命令行参数和插件通信）没有对应物，已去掉。
  - **按 Steam 好友加入**（GetJVP）：槽位里填好友的 17 位 SteamID64，加入时连本机 Steam 的 CEF 调试接口（127.0.0.1:8080）读取好友的加入参数。需要 Steam 开启 CEF 远程调试，连不上时会询问是否开启并重启 Steam。
- **命令行参数**支持 `minimized` `show` `server` `connect` `recover`，以及数据目录下的 `commandline.txt`（与原版共用同一个文件）。`recover` 只恢复联机状态（重新建房或连接上次的房间）；断网和禁卡状态任何时候启动都会接着显示；卡单状态不恢复——卡单靠挂起游戏进程实现，程序意外退出后请手动恢复。
- **战局锁密码多了几个限制**：除了原版禁止的竖线，还禁止 `<`、`>`、`&` 和连续减号，因为密码会原样写进 XML 文件。
- **联机协议与原版兼容**：线路格式照原版实现（GBK 编码、长度按字节算、同样的心跳和超时），可以和原版 0032 以后的版本互连，报告的版本号是 0216。「广播内容」四个开关在原版里存成一个数值，这里按位拆开，位的顺序是移植时自定的，所以这一项设置不能和原版的配置互相照搬。
- **收到队友的卡单广播后会自己兜底结束**：原版完全依赖对方发来的「停止」广播，那条广播丢了游戏会一直卡着；这里本机也按自己的卡单时长自动结束。
- **Bot 列表的主线路**只接受带 QuellGTA 版本标识的请求。经原作者同意，移植版也使用主线路：请求格式与原版一致，并在标识后面注明 `QuellGTA-WinUI/版本号`，方便服务方区分。主线路失败时改用两条辅助线路（xymm、lxcoo）。
- 界面文字目前只有简体中文。

## 尚未移植

依赖原版内嵌的外部程序：

- 自动骇入（AutoHack.exe）里的另外五种小游戏：滑块（slider）、闪烁（flashing）、弗利萨（fleeca）还没有移植；两种指纹（choose_fingerprint、sort_fingerprint）沿用「宏键」页已有的自动指纹，没有换成 AutoHack 的算法。源码在 [AutoHack_for_QuellGTA](https://github.com/mageangela/AutoHack_for_QuellGTA)。
- RTSS 相关的细节：手动输入帧数的热键模式、OSD 颜色自选、横排样式。
- 修改头像、帮会切换（RSCapi.exe）：**不移植**。这个组件要从其他进程的内存里取出 Rockstar 账号的登录凭据，再拿它调用 Rockstar 的内部接口。

纯逻辑但这一版没有做的：

- 自动切换双版本存档（传承版和增强版各用一份配置，切换游戏时自动换并重启）
- 意外退出后恢复卡单状态（联机状态可以恢复，见上面「命令行参数」）
- 热键的「代理模式」（原版三种引擎里的一种，没有读懂它的实现）
- 计时器的横排模式、文字刷新速率、多屏偏移菜单（偏移可以直接填数值代替）
- 伪后台的两个组合挂机方式合并成了一个「挂机时伪后台」开关
- 就地更新（下载新版并替换自身）

`扩展插件` 目录里的其他独立工具（PC 设置编辑器、QuellKJCC、HotKeySavior、武器选单优化器、飞行变强计时工具）没有反编译过。

## 目录结构

```
Native/      Win32 P/Invoke（NativeMethods：进程、钩子、输入；OverlayNative：分层窗口、托盘）
Services/    业务逻辑，不依赖界面。QuellCore 是总入口，其余每个文件对应一块功能
Views/       各个页面 + SettingRow 设置卡片控件 + Dialogs 确认框
Assets/      从原工程导出的资源，以及程序图标
```
